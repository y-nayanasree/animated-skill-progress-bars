
# Animated Skill/Progress Bars

A responsive skill dashboard built with HTML5, CSS3, and JavaScript.

## Features

- Five skill bars with labels and percentage values
- Animated progress bars using CSS transitions
- Animation triggered when the section enters the viewport
- Replay Animation button
- Responsive layout for desktop and mobile
- Accessible button focus styling
- Reduced-motion preference support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Intersection Observer API

## How It Works

Each skill has a `data-progress` attribute containing its target percentage.
JavaScript detects when the skills section becomes visible and updates each
bar's width. CSS transitions animate the change.

## Run Locally

Open `index.html` in a web browser.
